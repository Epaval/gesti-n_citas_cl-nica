# Sistema de Gestión de Citas Médicas 🏥

Sistema web desarrollado con **Django** y **MySQL** para la administración eficiente de un consultorio médico. Optimiza la agenda, protege los datos de los pacientes y digitaliza los procesos clínicos.

## ✨ Características principales

- 🔒 **Confidencialidad total**: La información de los pacientes está protegida y es de acceso restringido.
- 👨‍⚕️ **Gestión de médicos**: Control de especialidades y datos profesionales.
- 📁 **Expedientes digitalizados**: Almacenamiento seguro de historiales clínicos.
- 🛡️ **Control de acceso por roles**: Permisos diferenciados para administradores, médicos y personal.
- 📄 **Recetas e indicaciones digitales**: Se generan como documento externo (no se almacenan en la BD).
- 📅 **Calendario interactivo**: Visualización de citas por día y mes.
- ⏰ **Control de horarios**: Gestión de disponibilidad por fecha y médico.
- 📌 **Estados de cita**: Programada, en proceso, cancelada, completada, etc.
- ✅ **Activación de personal**: Control de usuarios activos/inactivos en el sistema.
